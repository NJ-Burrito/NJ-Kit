NJ-Narration: الصوت المناسب لقصتك، بلا ضجيج حوله.

مهارة لـ Claude Code تختار صوت الراوي وتنظّفه، وتفحص كل خطوة بسكربت يطبع PASS أو FAIL. وهي ضمن الإضافة منذ الإصدار 2.0.2.

اختر صوتا يناسب الشخصية
تصف الشخصية: العمر والأصل واللهجة والطبع. تحوّلها المهارة إلى أرقام وتقيس بها أصواتا مرخّصة.
اهندسه مرة واحدة من المصدر
يُنظَّف المقطع المرجعي مرة واحدة، ويُسجَّل كل سطر مرة واحدة. بلا إعادة تسجيل حتى يعجبك أحدها.
عالج الضجيج دون قصّ الكلمات
يُزال الفحيح قبل الجملة أو بعدها، ويتأكد الفحص أن الكلام نفسه لم يُمسّ.

مثال واحد، كنص

بيانات متخيَّلة لتوضيح شكل المخرجات. ليست قياسا حقيقيا وليست لشخص حقيقي.

BRIEF    narrator, woman, 40 to 55, calm, British English, dry room
TARGET   pitch 165 to 210 Hz, 130 to 150 words a minute, little echo
SOURCES  public domain or written consent only, one clip per speaker

REFERENCE CLIP (the one you will clone)
REF-QUALITY       FAIL  0.6 s of room tone at the start
                  # cleaned once, word-safe, then measured again
REF-QUALITY       PASS

EACH GENERATED LINE (one take)
TAKE-QUALITY      PASS
VOICE-EDGE-NOISE  FAIL  1.9 s of hiss after the last word
                  # cleaned without touching the speech
VOICE-EDGE-NOISE  PASS  speech samples identical

NEXT     the top 3 voices go to your ear. You decide.

ملاحظة صريحة. لا تأتي NJ-Narration بأي أصوات ولا بعينات صوتية. ولا تتضمن محرك توليد صوت ولا تختاره عنك: تحضر أنت صوتا مرخّصا ومحركا يحق لك استخدامه. الأرقام تقرّر ما يصل إلى أذنك، وأذنك تقرّر أخيرا.

التثبيت: السطران نفسهما لـ NJ-Kit في قسم التثبيت. وهي إحدى مهارات الإضافة الـ 24. بعد التثبيت قل “use nj-narration”. وبدون إضافات Claude Code انسخ المجلد nj-plugin/skills/nj-narration من المستودع.

مثبّت الحزمة

5 دقائق

المهارات الأربعون كلها على جهاز جديد. يحتاج إلى Python 3.10+.

git clone https://github.com/NJ-Burrito/NJ-Kit
cd NJ-Kit
python nj-kit/scripts/install.py --check   # preview, changes nothing
python nj-kit/scripts/install.py           # install
python nj-kit/scripts/fetch_assets.py --all # download NJ-Kit assets v1

ما الذي يغيره المثبت. يعرض قائمة 22 مهارة من مصادر خارجية، كل واحدة مثبتة على إصدار (commit) واحد ثابت، ويسألك قبل التنزيل (الخيار --yes يتخطى السؤال). ويضيف أيضا خطافات (hooks) وسطر حالة وحدودا في البيئة إلى ملف ~/.claude/settings.json مع نسخة احتياطية، ويضيف خوادم MCP إلى ~/.claude.json، ويكتب ملف ~/.claude/CLAUDE.md محايدا فقط إذا لم يكن لديك ملف. شغل --check أولا لترى كل شيء.

أين تُثبَّت المهارات، والخيارات
  • تُثبَّت المهارات في ~/.claude/skills/.
  • الخيار --scope project يضعها في مستودع واحد.
  • يتحقق fetch_assets.py من بصمة sha256 لكل ملف.

أسئلة عن NJ-Kit ومهارات Claude Code

ما هي NJ-Kit؟

NJ-Kit إضافة مجانية ومفتوحة المصدر لـ Claude Code: منهج عمل واحد و41 مهارة. تنتهي كل مهارة بسكربت فحص يطبع PASS أو FAIL. برخصة MIT، من صنع نادر الزغول.

ما هي مهارات Claude Code؟

المهارة مجلد فيه ملف SKILL.md يضم التعليمات، ومعه أي سكربتات يحتاجها. يقرأ Claude Code وصف كل مهارة ويحمّلها حين تطابق المهمةُ وصفَها.

ما هو الفحص؟

سكربت في نهاية المهارة يفحص النتيجة ويطبع PASS أو FAIL. وعند FAIL تُجري المهارة إصلاحًا واحدًا ثم تعيد الفحص. شاهد مثالًا.

كيف أثبّت NJ-Kit؟

في Claude Code نفّذ /plugin marketplace add NJ-Burrito/NJ-Kit ثم /plugin install nj-kit@nj-kit. يستغرق ذلك نحو دقيقة ويمنحك 24 مهارة، ويضيف مثبّت الحزمة الـ17 الباقية.

ما الفرق بين NJ-Kit ومستودع المهارات من Anthropic؟

مستودع Anthropic هو مجموعتها العامة من مهارات الوكلاء. أما NJ-Kit فحزمة مستقلة مبنية حول منهج عمل واحد، وتنتهي كل مهارة فيها بسكربت يطبع PASS أو FAIL. ويمكنك تثبيت الاثنين معًا. قارن بينها.

هل تعمل مع وكلاء غير Claude Code؟

يمكن لأي وكيل يقرأ ملفات SKILL.md استخدام مجلدات المهارات مباشرة بلا مثبّت. أما مسار الإضافة فهو لـ Claude Code.

هل NJ-Kit من Anthropic؟

لا. NJ-Kit مشروع مستقل من نادر الزغول، وغير تابع لشركة Anthropic ولا معتمد منها.

هل هي مجانية؟

نعم، مفتوحة المصدر برخصة MIT.

هل أحتاج إليها كلها؟

لا. انسخ مجلد مهارة واحدة إلى ~/.claude/skills/ ويعمل وحده.

هل تعمل بالعربية؟

نعم. العربية والإنجليزية بالمستوى نفسه، مع دعم الكتابة من اليمين إلى اليسار. وهذه الصفحة متاحة أيضًا بالإنجليزية.

هل تعمل المسارات على جهازي؟

نعم. اضبط المتغيرات التي تذكرها المهارة، مثل NJ_PLUGIN_ROOT، أو أبقِ القيم الافتراضية.
