  that repeated each other, restatements of the body, and explanations of

  paragraph, design-gate's "replaces eyeballing a screenshot").
- Frontmatter is now `description: '…'` on one logical line (single-quoted YAML,
  apostrophes doubled). `name` unchanged everywhere; no other fields exist in
  any of the 21. Verified by parsing each file with PyYAML: all 21 parse,
  `name` matches the directory, keys are exactly `['description','name']`.
- `bg-music` description now states it **holds** a bundled licence-cleared CC0
  SFX library and music beds with cue presets (the 17 MB moved from the removed
  `brag` skill) as well as sourcing tracks. No asset file touched.
- Trigger phrases that were only stylistic duplicates were dropped, e.g.
  10x's "senior engineer"/"make it robust" (kept "do this properly",

  opposite"/"challenge me", bg-music's "royalty free"/"what can I legally use".
  This is the one place where routing recall could measurably fall; if a skill
  stops being found on a phrase the owner actually uses, add that phrase back — the
  budget has 0–3 words of headroom per description.
