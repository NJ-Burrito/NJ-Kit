# Failure catalogue and what was tried

Read from `workflow-diagram/SKILL.md` when a symptom mid-build matches one of

shipped.

## Failure catalogue

Every one of these has actually shipped. Symptom first, because that is what you
will be handed.

| Symptom | Cause | Fix |
|---|---|---|
| A connector runs straight through a box | The route was chosen by «which side of the target is it on», so a return to a box **above** the line was sent into the channel **below** it and had to cross the line to get there | A shape's channel is a property of the **band it stands in**, not of the direction the connector travels |
| Two connectors run down the sheet on top of each other | A stub is anchored to its shape; a desk and the ending directly beneath it hand out ports at the same x, and no lane book can move either | Measure the finished routes for runs within 6 px and push a port aside; repeat until there are none |
| Every caption sits on the wrong side of its own line | `text-anchor` read as if the text were Latin | With `direction="rtl"`, `start` is the right edge |
| The chart title prints off the left of the sheet | Same cause, on the one run that has no anchor of its own | Anchor `start` at the **right** margin |
| A caption sits on somebody else's connector | The placer avoided shapes and other captions only | It must avoid every connector but its own, and take a knockout for that one |
| A straight run on the main line has a kink in it | The chain shared a face with a return, so its port was nudged off centre | The chain **owns the middle** of the face it runs through; only the others fan out |
| A decision is a lozenge four times as wide as it is tall | The wrap that fits in the smallest **area** is a single long line | Score the area, cap the half-width at 165, and charge for every extra line — a tall diamond raises the whole grid row |
| Three columns of paper across the bottom of the sheet | Grid rows packed to capacity — 25 over 4 is 7+7+7+4 | Balance the partition: 7+6+6+6 |
| A red circle with «أ», then «ؤ», «إ», «ئ» | Connector letters generated by codepoint arithmetic walk the hamza forms | There are no lettered connectors any more. A wrap is an arrow |
| A symbol in the figure that the key does not explain | The legend lists a fixed set | The legend is generated from the roles actually drawn |
| A box says three of the four things it should | `wrap()` capped lines and truncated silently | The cap is a runaway guard, not a layout budget. A box grows to fit |
| An empty framed box on its own page | The figure was taller than the page; the frame printed, the content broke | The drawing is scaled onto the page, so it cannot outgrow it |
| The chart is four times wider than the sheet | A desk was drawn as three columns | **One shape per desk**, plus at most one «إجراء» after it |
| An Arabic word broken mid-glyph across lines | Wrapping broke inside a word | Never break an Arabic word; let a too-long single word overflow |
| A lone `(` in an Arabic run renders as `)` | The opening bracket joined the Latin run | Isolate the bracketed Latin run |
| The fee table and the figure disagree on when payment happens | Payment timing derived twice, in two places | Derive it **once** and feed the table, the rule and the figure from it |
| A stage in the figure nobody can find in the portal | Carried over from the old SRS | Delete it; raise an open question instead |
| An **ending for a screen that does not exist** — «لا يسمح بتقديم الطلب» for the «لا» arm of a terms question | The applicant rows were a template, and the template assumed a refusal path. Leaving the undertaking boxes unticked leaves the button unresponsive: no message, no screen, no state | Build the applicant rows from the **walk log**, and mark them `template` where there is no walk. A drawn ending nobody can reach is worse than an omission — a reader cannot tell it from an observation |
| A **cancel ending hung on the submit screen** | «إلغاء» on the form's bar leaves the form; the BPMN has no cancel path before the process starts | Draw an ending only where the walk saw one |
| Two returns captioned «إرجاع **إلى** …» while the buttons say «إرجاع **لـ**…» | The caption was the converter's rendering of the flow name, compared to nothing | The caption dictionary, and `caption-check.mjs` |
| The whole model's structure vanishes from a figure the first time the service is walked | `harvest()` **chose** the walk file over the model file, and a walk record carries no `steps`/`graph` | Union, never a choice — the walk wins field by field, not file by file |
| A stage is on the sheet and in chapter 3, and **missing from chapter 6** | The figure, chapter 3 and chapter 6 each derived it from a different field of a different source, and one of those fields was dropped by a merge that picked | Union at every level, and a gate that holds the **document**, not just the drawing — `ledger-check.mjs`, plus `flow-fidelity.mjs`'s chapter-3/chapter-6 check on the assignment step |
| A desk's model-only facts (`autoAssigned`, `assignment`, `formKey`, `requiresComment`, `actionTargets`) disappear the first time the service is walked | The top-level merge was a union, but `desks` is a key **both** files carry, so one array replaced the other | Union **inside** the array too: match desks on the folded Arabic name, model fields as the base, observed fields over the top one at a time |
| A reconciliation line under the figure pushes the drawing onto a second landscape page | `flowSheet()` budgets a fixed chrome allowance and the line is not in it | Take the line's height off the art (`reconciliationMm`), not off the page count. The landscape-page count is the check that catches it. **Still open, and now measured, 2026-09-08:** at `reconciliationMm = 15` `food-product-registration` prints an empty frame on page 13 and the drawing on page 14. Bisected on the printed PDF — art of **121 mm fits, 125 mm does not** — so the allowance has to be **≥ 19**, and 22–23 is the safe number. It is nothing to do with the figure: rendering the *old* figure into the same document splits it in exactly the same place |
| Every role fill reads the same to a colour-blind reader | The fills were tints at 1.14–1.15 to 1 against paper, and a tint that pale has no chroma to carry a category with | Measure it — CIEDE2000 under a dichromacy simulation, over the pairs colour alone must separate. 0.35 under protanopia is a third of a just-noticeable difference. Anchor the fills on a scheme built for filled cells (Tol `light`) and let a search place each one's lightness |
| A refusal, a return and the forward path are three greys | One `WIRE` colour, one weight, one dash for every connector on the sheet | Three classes, each differing in **colour and weight and dash together** — and unobserved as a *second* channel crossed with all three, not a fourth class that swallows them |
| The way **out** of the rework task is the heaviest line on the sheet | The classifier looked at the target's role and at the spine's own order, and «إعادة الإرسال» has a target on the spine and a source off it — so neither test saw it | An edge **leaving** a rework-skinned stage (or the gate that carries its exits) is a return. Half a loop drawn as a return and half as the main path is a fork into a lane that only exists to come back |
| An arrow ends in a point of the wrong colour | An SVG `marker` inherits nothing from the path that uses it | One marker per class **per state**, each with its own stroke colour |
| A hard precondition («رقم كتاب تسجيل المنشأة») on no source at all | It carries no `formcontrolname`, and the model starts after it | `dump-form-controls.ts` emits `taq-*` verify widgets with a synthetic name and `verify: true` |
| A timer that cannot be shown to end the request by itself | It was a clock in a box and half of a merged caption | Give the boundary event its own shape |
| Untranslated `translation-not-found[actionKey.…]` on an edge | The portal has no string for that action | Match on the key, humanise it for the label, **and report the missing string** |
| Desks draw **no exits at all**, and the onward edge says «موافقة» on every one | The classifier tested a **folded** caption against **unfolded** patterns | **Fold the haystack, fold the needle** |
| A desk's button is missing from the figure entirely | The classifier knew only «رفض» and «إرجاع» | Classify onward / refuse / return, then handle *the remainder explicitly* |
| «الطلب مغلق» appears under a button that names a committee secretary | Unclassified actions swept into a terminal node | Only a caption that **settles** the outcome may draw one |
| A return loops back to the desk that pressed it | Every return used `returnsTo: <this desk>` | A caption that **names** a desk in the route wins over the default |
| Buttons like «إضافة», «عرض», «تحميل» drawn as exits | They are on every desk's bar and route nothing | Filter non-routing actions before classifying |
| The PDF checker reports `SegoeUI-*` embedded on the figure page only | A caption used «←»/«→»; Cairo has no arrow glyphs | **Write captions in glyphs the face actually has**, and end the family list at `sans-serif` |
| Type prints at 4 pt | The drawing was taller in proportion than the page, so height bound the fit | Search the grid-row count and score the printed size |
| Arabic in the figure copies out garbled («اإلرسال») and `check-pdf.py` reports a Type 3 font | SVG `<text>` was given a `stroke`/`paint-order` halo; headless Chrome embeds stroked text as Type 3 outlines | Never stroke text in a print-bound SVG; use an opaque plate rectangle behind the label |

## What was tried and does not work

- **A framed pool with one lane per actor.** Boundaries the drawing has to obey
  rather than information it carries: a lane a row does not use is still ruled
  and still costs its height, and the header costs a tenth of the width on every
  row. Who does what is carried by the **colour of the shape**, with the key
  naming the colours.
- **A lettered ring for a return that spans rows.** Two marks the reader has to
  match by eye, a 2 mm clearance rule to keep arrows off them, and a checker
  rule of their own. An arrow through a corridor says the same thing and can be
  followed.
- **Decomposing every exit into its own diamond.** Textbook form; measured at
  seventeen stages becoming thirty-six shapes and the type falling from 5.7 pt
  to 4.7. One «إجراء» per stage, and the exits leave it as labelled arrows.
- **Carrying less to fit.** Folding «الدخول», «بطاقة الخدمة» and the terms
  question into one start step bought about a point. It also deleted three true
  statements from the only picture in the document. Withdrawn 2026-09-07.
