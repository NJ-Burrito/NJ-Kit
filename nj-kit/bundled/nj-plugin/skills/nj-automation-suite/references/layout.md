## Scaffold order that worked
paths -> lock/browser/signin -> one service by hand -> reporter -> selftest -> generator (discover/generate) -> Jira (sync, checks, tracker) -> PDFs -> launchers -> Docker -> docs. Each step has its gate (SKILL.md); do not start the next while the gate is red.

## Per-service files
- `AGENT.md`: what the service is, how to run its tests, accounts CLASSES (not secrets), known portal defects, the commands for one test and one note. Regenerated by `tools/gen-agent-md.ts`, never hand-edited.
- `README-service.md`: human notes; sections added by the pipeline carry a verdict line first.
- `desks.json`: learned after the first approved run (desk names, actions); generated.
