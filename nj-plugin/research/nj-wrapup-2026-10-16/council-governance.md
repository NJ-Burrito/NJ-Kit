## New proposals

- **N-gov-1: three small scripts instead of prose gates.** `discover.py` (P1), `reconcile.py` (P9/P10/P17), `render_messages.py` (P19), plus a `risk_flags` step that derives the `risk` column and the worker count from plan.md (P3/P6). Each has an exit code and a selftest, no machine paths. Everything not scripted is labelled HABIT in the skill, as nj-delegate does for §0.3a.
- **N-gov-2: telemetry and budgets instead of a quota.** Each wrap-up writes one `relay.py batch` row, runs `relay.py verify`, and every lane brief carries `Governance: nj-governance-v3`, owned write path (`filed-<lane>.json`), a per-ticket token ceiling, stop-at-80%, QUESTION n/2 then `SKIPPED:` row, and a FOCUS line. Failed create = `SKIPPED`, never a retry loop.
- **N-gov-3: ship discipline.** The wrapup change is a skill change: update nj-kit (KNOWN_SOURCES, tooling, why notes), `export.py --zip`, extract to `<NJ_KIT_ROOT>`; move all PROJ material to `references/profile-PROJ.md` and run a dry read as a non-PROJ (MOA) session; list any step that cannot run. Count of PROJ-only commands left in the core must be 0.

## The one thing that must not ship

Gate sentences (P5, P6, P9, P19, P20) written as prose with no script and no exit code. v1's wrong header counts (16 keys stated as 17) came from exactly that; v2 would repeat it with more paperwork. If a gate has no script, it must say HABIT in the text, and P3's thresholds must never be written as quotas.
