# Consent record: one per speaker, signed BEFORE any recording

Store the signed paper and the recordings outside the repository; the repository holds only the date, the holder's
initials or id, the sha256 of each recording and where the paper is kept. Basis: a blanket "we may use your voice for AI"
is not enough (industry guidance, not law; research 2026-11-07). Have the wording reviewed by a lawyer before commercial use.

| Field | Entry |
|---|---|
| Speaker (legal name, kept off-repo) and id used in the project | |
| Identity check done by / date | |
| Project and characters the voice may play | name them; a new character or project needs a new record |
| Scope | AI voice synthesis (cloning a reference and generating speech) for the named project only; no other use |
| Channels | e.g. social video, the project's posts; regions; |
| Term | start and end date; what happens at the end |
| Disclosure | the speaker agrees that the audio is labelled as AI-generated where a platform or law requires it |
| Not allowed | sale or licence of the voice to others; use in political, adult or deceptive content; impersonation |
| Revocation | how the speaker withdraws (address, notice period); on withdrawal the project stops new use, deletes the reference and the clone, and records the deletion date; already published work: state what happens |
| Retention | how long raw recordings and the cloned reference are kept, and where |
| Payment | fee, what it covers (session, buyout of AI-synthesis rights), when paid |
| Recording | session date, script id, registers recorded, the number of files |
| sha256 of every recording | (list: file name, hash; computed after the session, before any processing) |
| Speaker signature and date | |
| Producer signature and date | |
| Minors | not applicable. A child's voice is never cloned: an adult actor performs the child register (`references/reference-prep.md`) |

Shortlist for finding talent (public pages, read 2026-11-07, none contacted): direct commission of Arabic voice actors with this
record; talent marketplaces whose terms you have read first; a studio-data vendor that documents per-talent consent in writing
(confirm Arabic and cloning rights in writing). Not for cloning: scraped audio, research-only corpora, marketplace voices whose
terms you have not read. Details: `references/engines.md` section 4.
